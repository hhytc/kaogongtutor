# 公考几何 3D 透视台 (KaoGong Tutor 3D)

> 专为公务员考试（国考/各省联考）行测“数量关系”与“图形推理”打造的 3D 交互式几何直觉训练器。

📱 **移动端优先设计** · 🎮 **Three.js 交互式触控** · 📐 **公考真题直通 3D 还原** · ⚡ **秒杀口诀图鉴**

---

## 🌟 五大核心实战训练模块

1. **立体表面展开与最短路径 (Unfolding)**
   - 动态滑块模拟圆柱外壁、正方体表面、圆锥侧面展开过程
   - 螺旋线与斜线实时映射，直观领悟“两点之间线段最短”与内外壁翻折法
2. **旋转体与体积拆解 (Solids of Revolution)**
   - 直角三角形、直角梯形绕轴 $0^\circ \sim 360^\circ$ 动态旋转扫掠
   - 圆台、圆柱+圆锥组合体、挖空体体积公式推导与分步解析
3. **空间截面四大金律 (Cross Sections)**
   - 交互式空间切片截正方体，动态高亮多边形截面交线
   - 预设截面：正三角形、正方形、正六边形、等腰梯形、矩形
   - 实证公考核心考点：“正方体截面绝无直角或钝角三角形”
4. **六面体折纸盒与空间重构 (Origami & Nets)**
   - **四大家族全部 11 种合法展开图**动态折叠（$0\% \to 100\%$）
     - ⭐️ 1-4-1 型 (6种)
     - 📐 2-3-1 型 (3种)
     - 🪜 2-2-2 型 (1种)
     - 🔀 3-3 型 (1种)
   - 考场秒杀三大陷阱：“田”字必死、“凹”字必死、“一线不过四”
   - 相对面颜色高亮、公共顶点金色标记珠、时针旋转方向对照
5. **立体拼合与空间旋转 (3D Assembly)**
   - $3 \times 3 \times 3$ 大正方体组件空间拼合体验
   - X/Y/Z 三轴 $90^\circ$ 离散旋转，凹凸咬合，数量守恒秒杀技巧

## 🛠️ 技术栈

- **框架**: React 19 + TypeScript
- **构建工具**: Vite 8
- **3D 引擎**: Three.js + OrbitControls
- **数学公式**: KaTeX
- **样式**: Tailwind CSS
- **图标**: Lucide React
- **特效**: Canvas Confetti

## 🚀 本地开发与构建

```bash
# 安装依赖
npm install

# 启动本地开发服务 (支持局域网手机访问)
npm run dev -- --host 0.0.0.0

# 生产环境打包
npm run build
```
